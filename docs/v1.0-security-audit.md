# v1.0 security audit

Local-only, unsandboxed Mac file browser/player. Not a web/MAS checklist.

- Date: 2026-09-03
- App: Skagway **0.80.0**
- Method: Cursor [Security Review](https://cursor.com) on the working-tree/main delta, then a **full pass** of Process / queues / privacy in shipped code (the delta did not touch those).

## Verdict: PASS (accepted residuals)

No medium+ issues that change 1.0 posture. Unsandboxed + user-chosen ffmpeg are **intentional**.

## Cursor Security Review (diff)

**No medium, high, or critical issues** in the current `main` working-tree delta (readiness docs, tests, Play All / rating / integrity extracts). Queues and ffmpeg were unchanged in that delta — covered above instead.

## Accepted residuals (do not block 1.0)

1. **Unsandboxed** — required for arbitrary folders + optional ffmpeg. Not going to the App Store.
2. **User-configured ffmpeg binary** — Settings path is run as `executableURL`. Same trust as the user account.
3. **Relaunch helper** (`DatabaseExportImport.relaunchAfterTerminate`) — writes `relaunch.sh` with `open "\(Bundle.main.bundlePath)"` and starts it via `launchctl` argv. Interpolates **app bundle path**, not library/media paths. Odd characters in the install path could break relaunch only.
4. **Collection `.matches` regex** — user-authored rules on their own library; local CPU only.
5. **Sparkle** — if the user enables auto-check, the Mac fetches the appcast. No library data.

## Out of scope

Mac App Store / sandbox, server-side auth, multi-tenant isolation.
