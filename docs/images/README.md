# User guide screenshots (aspirational)

The live manual is **machii-labs** `/skagway/manual` (screenshots live in that project’s `public/skagway/manual/`). `../USER_GUIDE.md` only points there.

The shot list below is leftover from an older in-repo guide idea. Prefer updating the machii-labs pages when docs change.

## How to capture

1. Use **Skagway 0.6.6** or newer.
2. Prefer **window ~1200×800** (or your usual size) and **light or dark** mode — pick one and stay consistent across shots.
3. Hide unrelated apps; use a **clean desktop** or blur if you share publicly.
4. Save as **PNG** (good for UI) into this folder with the filenames below.
5. In `USER_GUIDE.md`, change each `images/placeholder.svg` to the matching `.png` when ready.
